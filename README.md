# Zot-Life: Survive the Week at UCI 🎮🧋📚

A chaotic and hilarious game simulating the true UCI student experience. Your challenge? Survive the week!

## 💡 Features
- 🧋 Boba runs at UTC
- 😴 Oversleeping and last-minute Canvas alerts
- 📚 GPA stress & mental breakdowns
- 📢 Student life randomness

## 🛠️ Tech Stack
- HTML / CSS / JavaScript
- GitHub Codespaces for dev

## 🚀 How to Play
Open `index.html` in any browser and try to survive the UCI week by balancing your energy and mood!
